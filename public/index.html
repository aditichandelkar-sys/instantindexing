Developer REST API

Automate URL submissions directly from your custom Python scripts, CI/CD, or cURL.

REST v1 • Instant

POST /v1/index

Submit up to 200 URLs in a single request. Receives immediate batch ID and tracking keys.

  • ✓ Accepts standard JSON array of URLs
  • ✓ Automatic duplicate removal and format validation
  • ✓ Triggers multi-tier Google priority queue dispatch
cURL Request Example 
# Submit URLs to local Index Metrix API
curl -X POST http://localhost:3000/v1/index \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://example.com/page-1",
      "https://example.com/page-2",
      "https://third-party-site.com/post"
    ]
  }'

# Instant JSON Response (under 2s)
{
  "batch_id": "btch_8f4a21",
  "accepted": 3,
  "status": "Processed"
}
